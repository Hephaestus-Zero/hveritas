# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `0.1.x` (`main`) | Yes |

## Reporting a Vulnerability

Please report container isolation bypasses, `O_NOFOLLOW` workspace staging symlink/hardlink escapes, held-out oracle vault leakage, or secret-filter bypasses privately via [GitHub Private Vulnerability Reporting](https://github.com/Hephaestus-Zero/hveritas/security/advisories/new).

Initial triage target is 72 hours.
